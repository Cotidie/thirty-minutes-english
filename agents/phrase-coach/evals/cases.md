# 검증 시나리오

프롬프트를 고칠 때마다 사람이 아래 12개를 직접 말해 보고 확인한다. 한 시나리오는 30초, 전체 약 12분.

답변 길이가 이 에이전트의 주된 실패 모드다. 1·8번을 먼저 본다.

| # | 말하는 방식 | 기대 반응 |
|---|---|---|
| 1 | "눈치 좀 챙기라는 말 영어로 어떻게 해?" | 표현 하나를 두 번. 부연은 짧은 한 문장 이하. 10초 이내 |
| 2 | "I have much work this week가 맞아?" | 어색하다고 짚고 자연스러운 버전 제시 |
| 3 | "I'm swamped this week 어때?" | 이미 자연스럽다고만 하고 끝. 대안 만들어내지 않음 |
| 4 | "이거 좀 애매한데 영어로 뭐라 해?"(대상 불명) | 되묻기 한 번. 두 해석을 다 답하지 않음 |
| 4b | "in charge for the schedule... 이거 맞아?"(조각) | 완성된 표현(in charge of)만 제시. 뭐가 빠졌는지 설명하지 않음 |
| 4c | "I want to say... 음... 이 일정을 내가 맡는다고" (한영 섞임) | 영어 표현 하나로 답. 섞어 말한 것 언급 없음 |
| 5 | 질문 중간에 3초 멈췄다가 마저 말하기 | 끊지 않고 끝까지 기다렸다 답변 |
| 6 | 답을 듣고 따라 말하기 | "That's it" 한마디. 추가 설명 없음 |
| 7 | 답을 듣고 바로 다른 질문 | 새 질문에 답. 앞 질문으로 돌아가지 않음 |
| 8 | 관용구를 물어보기 | 관용구 + 평범한 대안 하나. 유래나 뉘앙스 설명 없음 |
| 9 | "고마워" 또는 "됐어" | "Goodbye" 한마디 |
| 10 | 옆 사람이 한국어로 떠드는 중에 질문 | 질문에만 답. 옆 대화 언급 없음 |

실패 기준:

| 실패 | 먼저 고칠 곳 |
|---|---|
| 답변이 10초를 넘음 | `## What a good answer contains` |
| 표현 뒤 설명이 두 문장 이상 | 같은 항목의 "at most one short sentence" |
| 뻔한 표현에도 설명을 붙임 | 같은 항목의 "speaks for itself" |
| 질문을 되풀이하고 답함 | `## 1) The question`의 "Do not restate" |
| 3번에서 없는 개선안을 만듦 | `## Choosing the expression` |
| 4번에서 두 해석을 다 답함 | `## When you are not sure` |
| 4b에서 문법 설명이 붙음 | `## Choosing the expression`의 "A fragment gets the finished phrase" |
| 답 뒤에 "도움이 됐어?"를 물음 | `## 1) The question`의 never 목록 |
| 9번에서 Goodbye 외의 말 | `## 3) Closing` |
| 한국어로 답함 | `# Language` |
