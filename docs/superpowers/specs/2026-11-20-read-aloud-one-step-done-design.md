# Read aloud: Done 한 번으로 끝내기

- 상태: 구현됨 (2026-11-20). 구현 계획: `docs/superpowers/plans/2026-11-20-read-aloud-one-step-done.md`.
- 범위: 문단의 Read aloud 라운드를 Done 한 번으로 끝낸다. 서버와 DB는 바뀌지 않는다.

## 목적

지금은 Done을 누르면 마이크와 Azure를 멈추고 기록을 저장한 뒤 "Round over" 상태로 남고, Close를 한 번 더 눌러야 패널이 닫히고 마이크가 풀리며 Read again이 눌린다. 두 단계일 이유가 없어졌으므로 Done 한 번으로 끝낸다.

## 사용자가 정한 것 (2026-11-20 대화)

1. Done을 누르면 멈추고 저장한 뒤 바로 닫힌다. 표시(형광펜)는 저장된 기록에서 다시 보여 그대로 남고, 눌러 코치 설명을 듣는 것도 그대로다.
2. Done 뒤에 보이던 "You: …" 문장과 초 수는 바로 사라진다.
3. 저장에 실패하면 닫지 않고 "Could not save this round."와 Close를 보인다. 이번 회의 마크도 남는다.
4. 시작에 실패했을 때의 Close는 그대로다.
5. 같은 세션의 다른 사람에게는 잠깐 "○○ finished"가 보인 뒤 저장된 기록의 표시로 바뀐다.

## 설계자가 정한 것

1. Done 전에 표시를 눌러 코치가 말하는 중이면, Done으로 닫혀도 그 통화는 끊지 않는다. 코치는 지금처럼 말이 끝나고 조용해지면 스스로 끊는다. Close(저장 실패, 시작 실패)는 지금처럼 통화를 끊는다.
2. 저장하는 동안의 짧은 순간에는 지금의 "Round over" 상태가 보인다. 문구는 바꾸지 않는다.
3. 저장이 끝나기 전에 페이지를 떠나면 지금처럼 아무 상태도 바꾸지 않는다.
4. 저장하는 동안에는 Close를 보이지 않는다. Close는 시작 실패와 저장 실패(새 단계 `unsaved`, 상태 문구 "Could not save this round.")에만 있다. 두 단계에 익숙한 사람이 Done 다음에 습관처럼 Close를 누르면 코치가 끊기고 저장 실패가 가려지기 때문이다 (최종 리뷰에서 나옴).
5. 다른 사람 화면은 끝난 회의 마크를 저장된 마크가 바뀔 때까지 붙잡는다 (`Paragraph`의 `useMarksWhileIdle`). 회가 저장 직후 끝나므로, 붙잡지 않으면 `records`를 다시 읽기 전까지 옛 마크가 잠깐 보인다 (최종 리뷰에서 나옴). 저장에 실패한 회를 Close로 닫으면 다른 화면은 다음에 `records`가 바뀔 때까지 그 회의 마크를 계속 보인다. 저장 실패가 드물어 받아들인다.

## 목표가 아닌 것

- 읽은 문장이나 초 수를 다른 곳에 남기기.
- 저장 재시도.
